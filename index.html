📘 Tutorial Aplikasi

Panduan singkat untuk staff unit & gudang.

1️⃣ Input Laporan Retur

  1. Ketik nama Anda, pilih dari saran.
  2. Isi tanggal retur dan ED.
  3. Ketik nama barang, pilih dari saran.
  4. Isi jumlah dan no batch.
  5. Pilih status barang.
  6. Klik Kirim.

2️⃣ Alur Status

Draft → Menunggu Dikirim → Diterima Gudang → Dimusnahkan / Dibatalkan.

3️⃣ Dashboard Gudang

Login dengan password untuk melihat monitoring, retur masuk, laporan expired, dan arsip.

4️⃣ Musnahkan Data

Di tab "Laporan Expired Diterima", klik 🗑️ Musnahkan untuk menandai barang sudah dimusnahkan. Data tidak terhapus, status berubah menjadi "Dimusnahkan".
